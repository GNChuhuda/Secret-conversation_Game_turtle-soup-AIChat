# 大侦探海龟汤游戏 - AI应用开发（Nocode开发）

## 一、项目概述
基于千问大模型的AI推理游戏。用户通过“是/否/无关”问答破解谜题，AI担任出题者和裁判角色。

# 环境安装指南
## NVM 安装
``` 
curl -o- https://raw.githubusercontent.com/nvm-sh/nvm/v0.39.1/install.sh | bash
```
## Node.js 18 安装
```
nvm install 18
nvm use 18
```
## 启动开发服务器
```
npm run dev
```
